# HomeLedger - Design System

Charte graphique adaptée du POC Ant Design vers Tailwind CSS + shadcn/ui.

## 🎨 Palette de Couleurs

### Light Theme
- **Primary**: `#1A5274` (Bleu professionnel) - `bg-primary`, `text-primary`
- **Primary Soft**: `#E6EEF4` (Bleu clair) - `bg-secondary`
- **Accent**: `#FF7A45` (Orange) - `bg-accent`
- **Success**: `#1FA37C` (Vert) - `bg-success`
- **Warning**: `#F59E0B` (Jaune) - `bg-warning`
- **Error**: `#E53935` (Rouge) - `bg-destructive`
- **Background**: `#F5F7FA` - `bg-background`
- **Card**: `#FFFFFF` - `bg-card`
- **Border**: `#E0E4EC` - `border`

### Dark Theme
- **Primary**: `#FF7A45` (Orange devient primaire)
- **Accent**: `#F97316` (Orange vif pour éléments sélectionnés)
- **Success**: `#36CFC9` (Cyan)
- **Warning**: `#FBBF24` (Jaune clair)
- **Error**: `#F87171` (Rouge clair)
- **Background**: `#050712` (Noir bleuté)
- **Card**: `#111827` (Gris foncé)
- **Border**: `#1F2937` (Gris moyen)

## 📐 Espacements & Dimensions

### Border Radius
- **Base**: `rounded-lg` (8px) - Inputs, selects
- **Large**: `rounded-xl` (12px) - Composants moyens
- **Extra Large**: `rounded-2xl` (16px) - Cards
- **Pill**: `rounded-full` (9999px) - Buttons, tags

### Hauteurs de Contrôle
- **Standard**: `h-8` (32px) - Buttons, inputs
- **Small**: `h-7` (28px) - Compact controls

### Padding
- **Base**: `p-2` (8px)
- **Large**: `p-3` (12px)
- **Card**: `p-4` (16px)

## 🔤 Typographie

- **Base Font Size**: 14px (`text-base`)
- **Line Height**: 1.5
- **Headers**: 15px pour card headers

## 🎯 Composants Clés

### Buttons
```tsx
// Primary
<Button className="rounded-full h-8 px-3.5">Action</Button>

// Small
<Button size="sm" className="rounded-full h-7 px-2.5">Small</Button>
```

### Cards
```tsx
<Card className="rounded-2xl shadow-card dark:shadow-card-dark p-4">
  <CardHeader className="text-[15px]">Title</CardHeader>
  <CardContent>Content</CardContent>
</Card>
```

### Inputs
```tsx
<Input className="rounded-lg h-8" />
```

### Tags/Badges
```tsx
<Badge className="rounded-full px-2 py-0.5">Label</Badge>
```

## 🌓 Dark Mode

Le dark mode utilise la classe `.dark` sur l'élément racine. Toutes les couleurs s'adaptent automatiquement via les CSS variables.

```tsx
// Toggle dark mode
<button onClick={() => document.documentElement.classList.toggle('dark')}>
  Toggle Theme
</button>
```

## 📦 Logos

Tous les logos sont dans `/public/icons/` avec le préfixe `logo-*`:
- `logo-main.svg` - Logo principal
- `logo-dark.svg` / `logo-light.svg` - Variantes thème
- `logo-horizontal.svg` / `logo-horizontal-light.svg` - Format horizontal
- `logo-mono-blue.svg` / `logo-mono-white.svg` - Monochromes

Usage:
```tsx
<Image src="/icons/logo-main.svg" alt="HomeLedger" width={120} height={40} />
```

## 🎨 Utilisation des Couleurs

### Texte
- Principal: `text-foreground`
- Secondaire: `text-muted-foreground`
- Sur primary: `text-primary-foreground`

### Backgrounds
- Page: `bg-background`
- Container: `bg-card`
- Hover: `hover:bg-muted`
- Active: `bg-secondary`

### États
- Success: `text-success` / `bg-success`
- Warning: `text-warning` / `bg-warning`
- Error: `text-destructive` / `bg-destructive`
