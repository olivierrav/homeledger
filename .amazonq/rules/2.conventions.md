# HomeLedger - Naming Conventions & Code Style

## 📝 Naming Standards

### Files & Directories
- **Components**: `PascalCase.tsx` (e.g., `TransactionList.tsx`)
- **Server Actions**: `kebab-case.ts` (e.g., `create-transaction.ts`)
- **Utilities/Libs**: `kebab-case.ts` (e.g., `format-currency.ts`)
- **Types**: `kebab-case.ts` (e.g., `transaction-types.ts`)
- **Route Folders**: `kebab-case/` (e.g., `app/(dashboard)/account-settings/`)

### Variables & Functions
- **Constants**: `UPPER_SNAKE_CASE` (e.g., `MAX_UPLOAD_SIZE`)
- **Functions**: `camelCase` (e.g., `calculateBalance`)
- **React Components**: `PascalCase` (e.g., `TransactionCard`)
- **Hooks**: `use` prefix + `camelCase` (e.g., `useTransactions`)
- **Server Actions**: Verb prefix (e.g., `createTransaction`, `deleteAccount`)

### Database
- **Tables**: `snake_case` plural (e.g., `transactions`, `user_accounts`)
- **Columns**: `snake_case` (e.g., `created_at`, `user_id`)
- **Enums**: `PascalCase` in code, `snake_case` in DB (e.g., `TransactionType` → `transaction_type`)

## 🎨 Code Style

### React Components
```typescript
// ✅ Server Component (default)
export default async function TransactionList() {
  const transactions = await db.query.transactions.findMany();
  return <div>{/* ... */}</div>;
}

// ✅ Client Component (only when needed)
"use client";
export function TransactionForm() {
  const [isPending, startTransition] = useTransition();
  // ...
}
```


### Imports Order
1. External packages (React, Next.js)
2. Internal aliases (`@/lib`, `@/components`)
3. Relative imports (`./`, `../`)
4. Types (group at end with `type` keyword)

### Comments
- Avoid obvious comments
- Use JSDoc for public APIs only
- Prefer self-documenting code

## 🚫 Anti-Patterns to Avoid

- ❌ `useMemo`/`useCallback`/`memo` (React Compiler handles this)
- ❌ `/api/*` routes for internal mutations (use Server Actions)
- ❌ `any` type (use `unknown` or proper types)
- ❌ Inline Zod schemas (define once, reuse)
- ❌ Client-side data fetching (use RSC)
- ❌ Prop drilling (use Server Components composition)
