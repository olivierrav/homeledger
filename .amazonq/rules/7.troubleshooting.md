# HomeLedger - Troubleshooting

## Problèmes Résolus

### Keycloak — Configuration locale
Keycloak est configuré en HTTP sur `http://keycloak.test:8080` (pas de HTTPS pour éviter les problèmes de trust TLS avec Node.js/undici).

**Prérequis :**
1. `keycloak.test` doit pointer vers `127.0.0.1` dans `/etc/hosts`
2. Docker doit être démarré : `docker compose -f env-local/docker-compose.yml up -d`

**"Something went wrong" sur Keycloak :**
- Vérifier les logs : `docker logs keycloak`
- Accéder via `http://keycloak.test:8080` (pas localhost)
- Vérifier que le port 8080 n'est pas utilisé par un autre service

**Redémarrer Keycloak :**
```bash
docker compose -f env-local/docker-compose.yml restart keycloak
```

### React Compiler
Le React Compiler nécessite `babel-plugin-react-compiler` qui n'est pas encore stable. Il a été désactivé dans `next.config.ts`.

Pour le réactiver plus tard :
```bash
npm install babel-plugin-react-compiler
```

Puis décommenter dans `next.config.ts` :
```ts
experimental: {
  reactCompiler: true,
}
```

### TypeScript et POC
Le dossier `poc/` contient l'ancien POC et peut causer des erreurs TypeScript. Il est exclu dans `tsconfig.json` :
```json
"exclude": ["node_modules", "poc"]
```

### Debug VSCode
La configuration de debug a été mise à jour pour afficher les logs dans le terminal intégré :
- `console: "integratedTerminal"` ajouté aux configurations
- Les logs Next.js apparaissent maintenant dans la console de debug

## Commandes Utiles

### Nettoyage
```bash
# Nettoyer le cache Next.js
rm -rf .next

# Réinstaller les dépendances
rm -rf node_modules package-lock.json
npm install
```

### Diagnostics
```bash
# Vérifier les erreurs TypeScript
npm run type-check

# Formater le code
npm run format

# Linter
npm run lint
```

### Base de Données
```bash
# Générer une migration
npm run db:generate

# Appliquer les migrations
npm run db:migrate

# Ouvrir Drizzle Studio
npm run db:studio
```

## Problèmes Connus

### Port 3000 déjà utilisé
```bash
# Trouver le processus
lsof -ti:3000

# Tuer le processus
kill -9 $(lsof -ti:3000)
```

### Erreurs de cache
Si vous rencontrez des erreurs étranges, essayez :
```bash
rm -rf .next
npm run dev
```
