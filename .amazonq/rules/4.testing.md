# HomeLedger - Testing Standards

## 🧪 Testing Strategy

### Test Pyramid
1. **Unit Tests** (70%) - Pure functions, utilities, validations
2. **Integration Tests** (20%) - Server Actions, DB operations
3. **E2E Tests** (10%) - Critical user flows

### Tools
- **Framework**: Vitest (fast, ESM-native)
- **React Testing**: @testing-library/react
- **E2E**: Playwright
- **DB Testing**: In-memory SQLite or test DB

## 📝 What to Test

### ✅ Always Test
- **Zod Schemas**: Valid/invalid inputs
- **Server Actions**: Auth, validation, business logic
- **Utilities**: Currency formatting, date calculations
- **Critical Flows**: Transaction creation, account balance

### ❌ Don't Test
- Third-party libraries (Drizzle, Auth.js)
- UI snapshots (brittle, low value)
- Trivial getters/setters

## 🔧 Test Structure

### Unit Test Example
```typescript
// lib/utils/format-currency.test.ts
import { describe, it, expect } from "vitest";
import { formatCurrency } from "./format-currency";

describe("formatCurrency", () => {
  it("formats positive amounts", () => {
    expect(formatCurrency(1234.56, "USD")).toBe("$1,234.56");
  });

  it("handles negative amounts", () => {
    expect(formatCurrency(-50, "EUR")).toBe("-€50.00");
  });

  it("throws on invalid currency", () => {
    expect(() => formatCurrency(100, "INVALID")).toThrow();
  });
});
```

### Server Action Test
```typescript
// lib/actions/create-transaction.test.ts
import { describe, it, expect, vi, beforeEach } from "vitest";
import { createTransaction } from "./create-transaction";

vi.mock("@/lib/auth", () => ({
  auth: vi.fn(),
}));

describe("createTransaction", () => {
  beforeEach(() => {
    vi.clearAllMocks();
  });

  it("throws when unauthenticated", async () => {
    vi.mocked(auth).mockResolvedValue(null);
    await expect(createTransaction({ amount: 100 })).rejects.toThrow("Unauthorized");
  });

  it("validates input schema", async () => {
    vi.mocked(auth).mockResolvedValue({ user: { id: "123" } });
    await expect(createTransaction({ amount: -50 })).rejects.toThrow();
  });

  it("creates transaction successfully", async () => {
    vi.mocked(auth).mockResolvedValue({ user: { id: "123" } });
    const result = await createTransaction({
      amount: 100,
      description: "Test",
      categoryId: "cat-1",
    });
    expect(result.id).toBeDefined();
  });
});
```

## 🎯 Coverage Goals

- **Minimum**: 70% overall
- **Critical Paths**: 90%+ (auth, payments, data mutations)
- **Utilities**: 80%+

## 🚀 Running Tests

```bash
# Unit + Integration
npm test

# Watch mode
npm test -- --watch

# Coverage report
npm test -- --coverage

# E2E
npx playwright test
```

## 📋 Testing Checklist

Before merging:
- [ ] New Server Actions have auth + validation tests
- [ ] Edge cases covered (empty, null, invalid)
- [ ] Error paths tested
- [ ] No skipped tests without reason
- [ ] Coverage doesn't decrease
