# HomeLedger - Security Standards

## 🔐 Authentication & Authorization

### Session Verification
```typescript
// ✅ MANDATORY in every Server Action
import { auth } from "@/lib/auth";

export async function sensitiveAction() {
  const session = await auth();
  if (!session?.user?.id) {
    throw new Error("Unauthorized");
  }
  // Proceed with user-specific logic
}
```

### Resource Ownership
```typescript
// ✅ Always verify user owns the resource
const transaction = await db.query.transactions.findFirst({
  where: and(
    eq(transactions.id, transactionId),
    eq(transactions.userId, session.user.id) // Critical check
  ),
});

if (!transaction) throw new Error("Not found or unauthorized");
```

## 🛡️ Input Validation

### Zod Schemas
- **MANDATORY** for all Server Actions
- **MANDATORY** for all form inputs
- Define schemas in `/lib/validations/`

```typescript
// ✅ Strict validation
const TransactionSchema = z.object({
  amount: z.number().positive().max(1_000_000),
  description: z.string().min(1).max(500).trim(),
  date: z.coerce.date().max(new Date()),
  categoryId: z.string().uuid(),
});

// ❌ Never trust raw input
export async function createTransaction(rawInput: unknown) {
  const validated = TransactionSchema.parse(rawInput); // Throws on invalid
  // ...
}
```

## 🔒 Data Protection

### Environment Variables
- **NEVER** expose secrets to client
- Prefix client vars with `NEXT_PUBLIC_`
- Use `.env.local` (gitignored)

```typescript
// ✅ Server-only
process.env.DATABASE_URL

// ✅ Client-safe
process.env.NEXT_PUBLIC_APP_NAME
```

### SQL Injection Prevention
- **ALWAYS** use Drizzle parameterized queries
- **NEVER** concatenate user input into SQL

```typescript
// ✅ Safe (Drizzle handles escaping)
await db.select().from(transactions).where(eq(transactions.id, userId));

// ❌ NEVER do raw SQL with user input
await db.execute(sql`SELECT * FROM transactions WHERE id = ${userId}`);
```

## 🚨 Error Handling

### User-Facing Errors
```typescript
// ✅ Generic messages to users
throw new Error("Transaction not found");

// ❌ Don't leak internals
throw new Error(`DB connection failed: ${dbError.stack}`);
```

### Logging Sensitive Data
```typescript
// ✅ Log actions, not data
logger.info({ userId, action: "create_transaction" });

// ❌ Don't log PII or secrets
logger.info({ email, password, creditCard });
```

## 🔑 Secrets Management

- Store in environment variables
- Rotate credentials regularly
- Use different secrets per environment (dev/staging/prod)
- Never commit `.env.local` or `.env.production`

## 📋 Security Checklist

Before deploying:
- [ ] All Server Actions verify `auth()`
- [ ] All inputs validated with Zod
- [ ] No secrets in client bundles
- [ ] Database queries use parameterization
- [ ] Error messages don't leak internals
- [ ] HTTPS enforced in production
- [ ] CORS configured restrictively
- [ ] Rate limiting on sensitive endpoints
